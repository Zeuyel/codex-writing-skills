# Verb-Adverb Discipline

## Purpose

This file turns “中文期刊风格” into a concrete micro-level rule set.

When a designated Chinese reference article exists, do not rely on intuition alone. Extract the article's actual verb-adverb and connector patterns, then keep the target manuscript close to that register.

Current default reference for `ai-innovation-lean`:
- `ref/人工智能技术应用如何影响企业创新_李玉花.pdf`

## A. Observed connectors from the reference paper

These connectors appear directly in the reference article and are safe defaults when the logic matches:

- `然而`
- `为了弥补这一不足`
- `例如`
- `进一步`
- `同时`
- `但是`
- `在此背景下`
- `基于此`
- `此外`
- `因此`
- `具体地`
- `进一步分析发现`
- `基于以上分析`
- `余文安排如下`

Use them only when the rhetorical move matches. Do not mechanically sprinkle them.

## D. High-risk verbs for this project

These words often sound like the author is controlling the writing process rather than analyzing the research object. Avoid them in manuscript body unless there is a strong reason:

- `收束`
- `压缩`
- `固定`
- `拉回`
- `写成`
- `锚定`
- `统摄`
- `装配`
- `回填`
- `对齐` when used metaphorically in theory prose

These words may be acceptable in notes, plans, or skills, but usually not in the paper body.

## E. Inflated verbs to use very cautiously

These often create AI-flavored prose if overused:

- `重塑`
- `赋能`
- `激发`
- `深化`
- `重构`
- `驱动` when used without a concrete object
- `塑造` when no mechanism follows

Do not ban them mechanically. Only use them when the object is concrete and the sentence lands analytically.

## F. Recommended checking routine

Before rewriting a chapter:

1. list the target paragraph's key verbs
2. list its adverbs and connectors
3. mark which combinations are observed in the reference article
4. replace writer-side meta verbs first
5. replace inflated verbs second
6. only then polish sentence rhythm

## G. Application to `ai-innovation-lean`

For this project, the manuscript should generally sound closer to:
- `本文利用……数据，分析……影响`
- `研究发现……`
- `进一步分析发现……`
- `现有研究开始借助……`
- `部分学者尝试利用……`
- `这为本文……提供基础`

and further away from:
- `本文将问题收束为……`
- `本文把对象压缩为……`
- `本文将后文写成……`
- `下文把这一链条固定为……`

The first group reads like article prose. The second group reads like drafting notes.
