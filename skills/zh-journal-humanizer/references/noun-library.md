# Noun Library

## Purpose

This file stores a conservative noun inventory for Chinese journal prose so the manuscript does not drift into vague, over-abstract, AI-flavored wording.

Use it dynamically:
- load only the part relevant to the chapter being revised
- prefer concrete analytical nouns over floating abstractions
- prefer nouns already used in the designated reference paper when possible

Current default reference for `ai-innovation-lean`:
- `ref/人工智能技术应用如何影响企业创新_李玉花.pdf`

## B. Combination-first nouns

These are common but too broad to be ideal core nouns when used bare. Prefer them inside a more concrete combination:

- `能力`
- `结构`
- `方式`
- `趋势`

Examples:
- `吸收能力`
- `组织能力`
- `任务结构`
- `人力资本结构`

## E. High-risk empty nouns

These often create vague AI prose if overused without concrete content:

- `逻辑`
- `脉络`
- `维度`
- `图景`
- `范式`
- `框架` when repeated too often without new content
- `体系` when no structure follows
- `内涵` when no definition follows
- `赋能效应`
- `转型动能`

Use them only when followed by concrete explanation.

## F. Preferred checking rule

When revising, ask:
1. does the noun point to an observable object, mechanism, or variable
2. is it supported by the reference register or batch-validated admission list
3. can a more concrete noun replace it
4. does the paragraph contain too many abstract nouns in a row
