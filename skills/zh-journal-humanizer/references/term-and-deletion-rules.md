# Term and deletion rules

## Preferred terminology

- `empirical` -> `实证上`, `实证层面`, `实证部分`
- `theory-driven empirical paper` -> `理论驱动的实证研究`
- `regime` -> `区间`, `状态区间`, `组织区间`
- `signal` -> `前瞻信号` or `前沿信号` depending on whether timing or location is emphasized
- `path choice` -> `路径选择`
- `organizational choice` -> `组织选择`
- `baseline regression` -> `基准回归`
- `mechanism analysis` -> `机制检验` or `机制分析`
- `robustness` -> `稳健性检验` or `稳健性分析`

## Delete or compress these by default

Unless they are the direct contribution of the paper, remove or compress:
- Lean4 or proof assistant workflow
- compilation environment and software setup
- coding or verification pipeline
- prompt design process
- data cleaning scripts and implementation details
- long self-praise about contribution
- empty significance claims with no analytical content

## Common Chinese-journal fixes

- Replace translated-English rhythm with clearer Chinese sentence order.
- Prefer `实证上` to `经验上` when the text refers to empirical analysis.
- If a sentence performs too many functions, split it.
- If a paragraph opens with details, add a 帽子句 first.
- If a paragraph ends without a landing, add a summary or bridge sentence.
- If a section repeats the introduction, compress and restate only the local task.

## Red flags to catch on the final pass

- repeated `不是……而是……` contrasts
- repeated `一方面……另一方面……` without real contrast
- repeated `需要指出的是`, `由此可见`, `这意味着`
- stacked abstract nouns with no concrete subject
- inflated verbs with weak objects
- generic endings such as `具有重要意义`, `提供启示`, `值得关注` without a concrete statement
