# Literature authority and process guardrails

## Core principle

Do not write literature-positioning claims into a manuscript unless they are grounded in a real literature review process.

This includes claims such as:
- `现有研究多从……展开`
- `既有文献较少关注……`
- `鲜有研究讨论……`
- `本文的核心新意在于……`
- `据我们所知，尚无研究……`
- `该方向尚未被系统讨论`

If these claims have not been verified from curated literature materials, treat them as unverified and do not write them into the paper as facts.

## Approved evidence sources

Prefer the user's curated literature base over ad hoc memory or lightweight search.

High-authority sources include:
- Scopus export files or records
- Web of Science export files or records
- EndNote libraries
- BibTeX or RIS files exported from formal databases
- user-curated review notes built from those exports
- locally stored PDFs that have already been screened into the project literature base

## Project-specific reminder

If the project already has a literature base in a sibling or parent directory, inspect that first before making novelty or gap claims.

For this project family, relevant materials may live in places such as:
- `../毕业论文/My EndNote Library.enl`
- `../毕业论文/core.bib`
- `../毕业论文/core.txt`

If such materials exist, they take precedence over speculative positioning based on memory.

## What not to do

Do not:
- infer a literature gap from a few remembered papers
- infer novelty from a quick keyword search alone
- convert an intuition into a manuscript claim
- write confident positioning language before checking the curated literature base
- use writing fluency to fill literature-review gaps

A polished sentence is still invalid if its literature basis has not been checked.

## What to do instead

When literature authority is incomplete:
1. state that the positioning is provisional
2. separate `idea`, `working conjecture`, and `verified literature judgment`
3. keep manuscript wording conservative
4. move speculative judgments to notes, not to the paper body

Use formulations such as:
- `本文的研究动机在于……` rather than `现有研究尚未……`
- `一个有待进一步核对的判断是……`
- `从当前已整理文献看，……` only if there is a real curated base behind it

## Writing rule for manuscript drafting

Before writing any literature-gap, novelty, or authority claim, ask:
1. Have I checked the user's curated export-based literature base?
2. Can I point to actual records or notes behind this sentence?
3. Is this statement verified, or is it only plausible?

If the answer to any of these is no, do not write the claim as fact.

## Scope control

The skill may help improve rhetoric, structure, and terminology.
It must not overstep into unsupported literature adjudication.

If the user asks for a stronger claim than the evidence supports, explicitly mark the claim as needing literature verification rather than silently upgrading the wording.
