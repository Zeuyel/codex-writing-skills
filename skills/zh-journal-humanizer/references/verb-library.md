# Verb Library

## Purpose

This file stores a conservative verb inventory for Chinese economics and management journal writing.

Use it dynamically:
- load only the relevant section when revising a specific chapter
- prefer phrase-level use, not isolated word substitution
- when a designated reference paper exists, prioritize verbs actually observed in that paper

Current default reference for `ai-innovation-lean`:
- `ref/人工智能技术应用如何影响企业创新_李玉花.pdf`

## C. Observation-layer only

These are frequent but should not be treated as core style anchors in manuscript body unless context requires them:

## E. Writer-side meta verbs to avoid in manuscript body

These usually belong in notes rather than article prose:

- `收束`
- `压缩`
- `固定`
- `拉回`
- `写成`
- `锚定`
- `统摄`
- `装配`
- `回填`
- `对齐`
- `落地` when used abstractly

## F. Inflated verbs to use cautiously

- `重塑`
- `赋能`
- `激发`
- `深化`
- `重构`
- `塑造`
- `驱动`

Use only when the object is concrete and the sentence lands analytically.

## G. Preferred checking rule

When revising, check in this order:
1. is the verb analyzing the object, or narrating the writing process
2. is the verb observed in the reference register or validated in the batch screen
3. does the verb pair naturally with its object
4. does the sentence still sound like article prose after replacement
